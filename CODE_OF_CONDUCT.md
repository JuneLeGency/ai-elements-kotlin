# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
We want a friendly, harassment-free community for everyone, whatever their background or
experience.

In short: be respectful and constructive, assume good intent, and focus on what is best for the
project and its users. Harassment, personal attacks and discriminatory language are not accepted
in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behaviour privately to the maintainers through a
[private security advisory](../../security/advisories/new) (it reaches the maintainers only), or by
contacting a maintainer on GitHub. Reports are handled confidentially. Maintainers apply the
Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
